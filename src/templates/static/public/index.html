It ships.

Every file in public/ is a page on your site. You are looking at public/index.html.

  1. Edit this file. bun dev shows it locally.
  2. Connect your server once with bun ship:setup.
  3. After that, every deploy is git commit and bun ship.

Writing with Astro, Jekyll, or Eleventy instead? Run bun ship:setup inside that project; Ship deploys any build folder it can verify.
